## 一、学生视角体验（任意 55 个专业的学生）

### 首次使用（屏④ 引导）
进 planner → 检测账户无专业 → 自动弹 3 步引导：
1. **选专业**（搜索全校 55 个本科专业）
2. **选入学学期**（如 2025 Autumn）
3. **自动生成四年默认课表**——完整版**仅 DSAI**（人工核对的官方 Study Plan + 当前学年/毕业年）；其余 54 专业 template 为空、从空白规划开始（公开 PDF 无按年学期数据，无法生成默认排表）

完成 → 进入主屏。

### 主屏（屏① 规划）
- **绿渐变 hero 卡**：距毕业还差 X 学分 + 进度环（54%）+ 毕业年（2029 春）
- **分类竖条进度（数据驱动）**：DSAI 为 6 类（核心/选修/项目/通识/英语/大学核心）；其余专业 4-5 类（如 BA 无英语类），UI 按该专业的 categories 自适应渲染
- **系统建议卡**：推荐下学期排课（基于未满足类别 + 先修）
- **年份 tab**（Y1 / Y2 当前 / Y3 / Y4）+ 当前年两学期课表（一屏滚动）
- 底部 seg-bar（规划 / 课程 / 通识）

### 课评（屏②）
点任一课程 → 课程详情：
- **三维评分**：给分松紧 / 工作量 / 收获感（进度条 + 分数）
- **避坑标签云**：给分好 / 作业多 / 收获大 / 开卷考 / 小组项目…（点投票 + 计数）
- **同学评价**（最新 + 星级）
- 冷启动：评价少时显「抢首评」

### 通识 GE（屏③ + ⑤ + ⑥）
- **选 GEN（屏③）**：73 门按 23 领域分组；本专业领域（DSAI=数学统计）自动灰色禁选；点选即标记「已选」
- **评分榜（屏⑤）**：高分 GE 排行，可切换排序（综合分 / 给分松 / 收获大 / 工作量低）；本专业领域隐藏；冷启动无评分显「抢首评」
- **教程（屏⑥）**：
  - A. 在本应用选好（选 2 门 / 不同领域 / 避开本专业，3 步）
  - B. 去 MyHKMU 注册（官方 5 步：登录 → 点专业 → Classes & Enrolment → Enrolment → Add Course Enrolment → Class Search 搜课号 → 提交查课表）
  - 时间提醒：2026 秋 自选期 8/24-26、add/drop 9/1-11，先到先得
  - 底部「看官方 Instruction Kit（PDF）」

### 排课台（B）
- 每门课下拉「改学期」（灵活排：这学期不修下学期修 / 提前修）
- 先修验证提示
- 用户 planned 优先于默认 template 学期

### profile 切换专业
- profile 我的页「我的专业 + 切换」→ 搜索 + 确认 → planner 反映新专业
- planner 主流程**不做**切换（防误切，切换是低频设置操作）

## 二、全专业完整（Phase C）
55 个本科专业（1 手排 DSAI + 54 生成）都能**算毕业进度**，不再只读 catalogue。数据模型：每专业 categories（各含 min_credits/courses）；**elective 一律 `pool:"credits"` 学分池**——从菜单修满学分即满足，兼容小池与 150 门 STEAM 菜单；GE 池动态解析 + pick_n。PDF 非标段落折叠进标准类（concentration/临床实习/核心科学等 → core；periphery/specialization → elective）。默认课表仅 DSAI 有；毕业进度计算全专业可用。

## 四、三标准保证 + 诚实边界

### 1. 全专业（55 完整）
- **把握**：95%+（已验证：3 个子 agent 独立读 PDF 交叉核对 55 专业，学分数字层零残留 mismatch）
- **保证**：Playwright 抓 55 个毕业规则 PDF（过 CF，DSAI gate 已证）+ **确定性解析器**按 5 学院表头变体调则（非 LLM 抽取）+ 子 agent 交叉验证 + `test_graduation`（55 专业 Σmin==total + 端到端「修完即毕业」）
- **边界**：多 cohort 4 文档（STAMJ/STEMJ/FTSJ/PWSJ）core 课单为「按 prose min 截断」启发式（min 已核，课单成员未逐课核）；332 个课程码不在公开课程树（格式全合法、学科前缀聚集，判真；个别若是幽灵则 fail-safe 占位不影响计算）

### 2. 信息准（对齐官方）
- **把握**：95%+
- **数据源全官方**：DSAI 人工核对 Study Plan / GE 73 门 Selection Guide（2026-08-07）/ 55 专业 programme PDF / 选课 Instruction Kit
- **保证**：解析对齐 PDF + DSAI golden sample gate（已通过）+ graduation 自动测试
- **边界**：学期 / 先修课官方公开渠道不全（部分课学期缺，标「待补」）；55 专业逐门课 100% 准靠自动测试 + 学生实测抽验（单 cohort 专业高置信；4 个多 cohort 专业课单为截断启发式）

### 3. 流程对（选课流程）
- **把握**：90%
- **数据源**：官方 Instruction Kit PDF + Course Enrolment System 页（2026 秋日期）
- **边界**：Instruction Kit 标注 2021-10 更新；菜单架构（Classes & Enrolment > Enrolment）是 HKMU 长期结构大概率没变，但 **2026 MyHKMU 界面微调需登录实测确认 ④-⑧ 按钮名**

### 总体
官方数据源 + 自动验证 + 学生反馈 + beta 标注 → **95%+ 质量**。不打包票 100%（那是骗人），但上线后实测快速修边角，比「打包票然后学生用着出错」靠谱。
