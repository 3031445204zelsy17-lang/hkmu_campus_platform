## 1. 全局共通机制(跨页)

- **启动流**:onLaunch→`_captureInvite`(捕获 `?inv=` 存 globalData,登录后 home 消费)→`auth.bootstrapSession()`(GET /users/me 单例去重;有 session 顺带 fetchUnread 设角标)。onError/onUnhandledRejection→微信实时日志。
- **页面**:17 页注册;`navigationStyle: custom` 全站自绘导航;自定义 tabBar 5 页(home/community/messages/planner/profile)。
- **tabbar**:纯 CSS 图标+「液态胶囊」拖动定位条(catchtouch 跟手 28ms 节流、松手 180ms 后 switchTab、1200ms 切换锁、10s 自愈);未读角标仅 messages tab(99+ 封顶,来自 messages 单例事件);各 tab 页 onShow `syncTabBar(page,index)`。
- **语言切换**:app-header 三语按钮→setLocale 写 storage→languagechange 事件→当前页 applyLocale 全量重建+tabbar 刷新;默认 zh-Hans。
- **跨页刷新**:一切写操作(发帖/删帖/点赞/评论)成功 bump `postsRevision` 单调计数器;home/community onShow 比较不清零→重拉。
- **request 层**(utils/request.js):唯一 HTTP 封装;Bearer+**401 单例 refresh rotation**;10s 超时;错误分类 network/timeout/server/client;`X-Client-Platform: wechat-miniprogram`;API_BASE 硬编码 `https://hkmu-campus-sea.azurewebsites.net/api/v1`。
- **常量**:PAGE_SIZE feed=12/list=12/comments=50;上传压缩档 头像200px/配图750px/评论480px(jpg q0.8,canvas 压缩后 wx.uploadFile 直传**绕过 request 层**、401 不自动刷新)。
