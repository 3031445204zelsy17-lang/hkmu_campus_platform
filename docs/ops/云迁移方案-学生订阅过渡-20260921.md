## 前提事实（推导的地基）

1. **无 ICP 备案域名**（2026-08 实证修正）：小程序白名单里是裸 `azurewebsites.net`,微信实践放行海外域名;小程序做的是主体备案≠域名备案 →「绑备案域名解耦」不成立,已从方案中剔除
2. **在线小程序不可断服**：正式版 1.10 线上、硬编码 Azure URL、审核状态本就脆弱(8-17 被拒过)→ 换任何域名 = 立即断服 + 赌一次白名单审核
3. **唯一零审核动作 = Azure 内同名重建**(删旧站→同秒同名建新站,azurewebsites.net 自动指新站,客户端零改动)
4. **学生订阅 $100/357 天在账未动**(id 617aff7e,az 须 --refresh 可见);仅 5 个允许区(欧/巴西),东南亚官方焊死不可解
5. **流量谷底**:选课季 9/14 结束、iOS=TestFlight 小规模、DAU 个位数 → 欧洲区 +250ms 的代价现在无关痛痒;真要低延迟是 12 月小程序复活/春季选课

## 阶段 1:本周迁学生订阅 francecentral(~2h,runbook)

1. 学生订阅建 RG `rg-hkmu-sea`(francecentral);**先验 B1+ACR SKU 可用**(允许区≠SKU 必可用,研究红旗#6)
2. 建 ACR `hkmucampusregstu`(Basic)+ `az acr import` 镜像 a2b16f3(服务端拷贝)
3. 建 B1 计划 + LA workspace + App Insights 组件(新连接串)
4. 深夜窗口:删 PAYG 站 `hkmu-campus-sea` → **同名**重建 → container set 四参(坑1)+全量 appsettings(存档 /tmp/appsettings_old.json,换 ACR 凭证+新 AI 串)→ minTls1.2/ftps 对齐
5. 验证:/api/health + /api/v1/courses/ge + 登录链路;浸泡
6. 清 PAYG:删 B1 计划+ACR(PAYG→$0,空订阅留作回滚壳;旧 AI/workspace 留历史 $0)
7. 守门三件套:budget alert $15 + cost.sh 双订阅版 + 每周飞书账单播报(复用 keepalive Actions+webhook)
8. 收尾:deploy.yml CI 目标改学生订阅、deploy-azure skill 同步、memory 记档

停机:15-30 分钟(深夜,DAU 个位数)。回滚:PAYG 重建(镜像在学生 ACR,admin 凭证跨订阅可拉)。

**效果:HK$145/月 → $0(额度撑~5.3个月至2027-02)。**
