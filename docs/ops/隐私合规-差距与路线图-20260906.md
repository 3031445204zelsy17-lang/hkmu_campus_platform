## 三、合作前三件事(草案,待法务复核)

### 3.1 数据保留与注销政策(草案 v0.1 ⚖)

| 数据类别 | 保留期 | 到期处理 |
|----------|--------|----------|
| 账号资料(邮箱/昵称/学号/OpenID) | 账号存续期 + 注销后 30 天 | 删除或匿名化 |
| 用户公开内容(帖/评/失物/课评) | 账号注销后 ⚖ | 删除 或 匿名化保留(社区惯例为匿名化,法务定) |
| 站内消息 | 随账号注销 | 删除 |
| 遥测/服务日志 | 90 天滚动 | 自动删除(Azure App Insights/日志默认保留期**未复核**,需门户核实后定) |
| 邮箱验证 token | 过期即失效 | 已实现(`email_tokens`) |

注销流程(草案):邮件申请 → 身份验证(注册邮箱回信)→ **14 个工作日**内处理 → 回执确认。
(14 个工作日为内地 App 惯例参考值;香港 PDPO 无强制时限,⚖ 法务定适用值。)
工程侧待办:注销自助入口 + 处理时限的产品化(见第四节)。

### 3.2 数据安全事件应急流程(草案 v0.1 ⚖)

**触发**:个人资料被泄露/未授权访问/丢失/篡改,或有系统被入侵的合理怀疑。

| 阶段 | 动作 | 时限(建议值 ⚖) |
|------|------|------------------|
| 发现记录 | 来源:Azure Monitor 告警/用户举报邮件/微信平台通知;记录时间、来源、影响面 | 立即 |
| 评估遏制 | 判定是否属个人资料事件;改密/下线/封端口 | 24 小时内 |
| 决定通报 | 用户邮件告知;PCPD 自愿通报(现阶段);若 PIPL 适用则强制通报监管与个人 ⚖ | 72 小时内 |
| 复盘 | 原因、措施、修订本流程 | 事件关闭后 7 天 |

联系人:第一责任人 SYF(mucp.official@gmail.com);学校合作后追加校方联系人。
每半年桌面演练一次(半天,过一遍流程)。
(72 小时为 GDPR 惯例参考;PDPO 现行法下数据泄露通报属自愿性 ⚖,法务确认。)

### 3.3 私信条款研讨稿(⑥ 挂账)

现状事实(2026-09-06 核):私信文本经 msgSecCheck 自动检测;私信无举报入口;管理员无产品面入口读私信。

- **选项 A(推荐)**:「站内消息仅收发双方可见;为履行内容安全义务,消息文本经自动化安全检测;依法配合监管要求时在必要范围内提供。」
- **选项 B**:维持原文绝对表述——不推荐,其余条款今日已对齐,独留一条不实表述扎眼。

研讨问题:①接受 A 措辞?②是否给私信加举报入口(加了则需再补一类可见性披露)。
