## 验收流程

1. 施工会话完成批次 N,commit 到 feature/course-data-fix
2. 在保留上下文的会话说「验收批次 N」
3. 验收者:拉 diff → 按上单逐项核 → 跑 CI/pytest → 抽查官方 PDF 原文
4. 结果三态:✅ 过 / ⚠️ 有条件过(列补救项)/ ❌ 打回(列原因)
5. 验收记录追加到本文件底部(批次、日期、结果、遗留)
