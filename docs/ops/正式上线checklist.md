## 🔴 P0 域名 / ICP(⚠️ 最大结构风险,先查清!)
微信「服务器域名」4 大硬性要求(官方 [网络能力说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)):① 必须 HTTPS ② 不能用 IP/localhost ③ **域名必须经过 ICP 备案** ④ 一个月最多改 5 次;新备案域名微信侧约 **3 天**同步。

- [ ] **核查(最高优先):当前后端 `hkmu-campus-sea.azurewebsites.net`(Azure 共享域 + Southeast Asia 海外服务器)能否用于正式版?**
  - 风险:ICP 备案要求「**自己拥有的域名 + 境内服务器**」。`*.azurewebsites.net` 非自有域、SEA 非境内 → **大概率备不了案 → 正式版用不了**(开发/体验版靠「不校验合法域名」绕过,正式版绕不过)。
  - 解法 A(若必须备案):上**自有自定义域名** + ICP 备案 + 指向后端(可能需境内服务器/CDN 接入)。
  - 解法 B:HK 主体/海外服的特殊路径 → **先向微信确认你这类主体的最新政策**(可能豁免或走另一套)。
  - 参考 [Azure ICP 备案 FAQ](https://www.azure.cn/support/icp/icp-faq/)(多级域名备案规则)。
- [ ] 服务器域名(request/socket/upload/download)在微信后台「合法域名」配齐 + 等同步。
