## 🔴 P0 域名 / ICP(2026-07-26 已核查;最大未知 = 后台零成本实测 + 类目)

微信「服务器域名」官方要求([网络能力说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)):① HTTPS ② 非 IP/localhost ③ **域名必须经过 ICP 备案** ④ 一个月改 ≤5 次。

**核查结论(2026-07-26 子代理多源交叉)**:
- ✅ `*.azurewebsites.net` **本身 ICP 备不了案**(高置信):非自有域 + Azure 全球 SEA 不在世纪互联备案范围 + 无备案号。
- ⚠️ 但 **HK/境外主体小程序大概率豁免 ICP 备案**(中置信,截至 2025-02):微信官方社区账号「境外小助手_simin」2025-02-12 明确回复「**当前境外主体小程序无需备案和年审**」([原帖](https://developers.weixin.qq.com/community/minihome/doc/000668c6074bd8dce7d2ff81e67000))。⚠️ 社区回复非正式公告 + 灰区,政策可能收紧。
- ⇒ 若豁免属实 → 当前 Azure 域**可能可直接用**,备案不是死结;但有两个**未明文**灰区须先验。

| 功能 | 所需类目 | 判定 |
|---|---|---|
| 选课规划工具 | 工具-效率 | ✅ 最稳,几乎零审核 |
