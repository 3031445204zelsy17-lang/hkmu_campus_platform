- **多端共享后端代码**(一套 FastAPI),但**部署 + 数据分轨**(合规边界不同):
  - 小程序(内地生)→ 纯选课工具,**无后端**(课程数据打包)→ 见阶段 1
  - App 国区 + 网页(全功能,所有学生)→ 境内后端 + 内地生数据境内 DB → 见阶段 2
- **arch-check 四大修正(必读)**:① 境内反代转发境外后端 = **违规**(别碰) ② App Store **国区**也要 APP 备案(工信部 105 号文) ③ 个人主体**过不了 UGC**(失物/论坛/社区) ④ 内地生数据存境外 Supabase **触 PIPL 跨境**。

5. 域名/ICP:小程序快路径免(无后端);阶段 2(App/网页)强制。
